Virtualization Mode Overview

17 November 2026Feature update+12 / −8 lines

In brief

The documentation now states that hyperconverged storage configuration is unavailable, and that editing a network intent template affects only future deployments. Existing Network ATC intents must be managed with PowerShell cmdlets. The installation link and Networking view terminology were also updated.

What Windows Server admins need to know

Administrators should not expect template edits to change existing hosts or clusters and should use Network ATC PowerShell cmdlets for deployed intents.

How it works

Virtualization Mode deploys as an appliance on physical or virtual machines. For more information about the installation requirements, see Install Windows Admin Center Virtualization ModeInstall Windows Admin Center Virtualization Mode.

This mode uses a client-server architecture with a web-based gateway and local agents on managed Hyper-V hosts. The gateway handles user authentication, request routing, and maintains a stateful database, while agents perform operations on hosts. TLS secures communication between the gateway and agents.

Profile types:

  • Compute: Hosts provide compute virtualization.
  • Storage: Storage systems for virtual machines (SAN,machines, including SAN, NAS, or hyperconverged using Storage Spaces Direct).and Scale-Out File Server resources. The Storage view displays onboarded storage devices linked to your compute systems. TheHyperconverged storage host profileconfiguration isn't available at this time.
  • Networking: Software Defined Networking (SDN) services for virtual machines. The NetworkNetworking view lets you manage network intent templates. The networking host profile isn't available at this time.

Network intent templates

Windows Admin Center Virtualization Mode introduces a concept called a Network intent template, which is an abstracted, predefined intent that you didn't yet apply to a network adapter or associate with a cluster or standalone host. A network intent template serves as a blueprint that you can use to create intents after you specify which NICs the template should apply to.

Network intent templates persist across sessions. After you create a template in the Add Resource workflow, it's saved and available for reuse the next time you onboard new hosts or clusters. You can select a saved template from the dropdown without recreating it. For more information about configuring network intent templates during onboarding, see Add resources in Virtualization ModeAdd compute resources in Windows Admin Center Virtualization Mode.

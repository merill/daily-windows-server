Windows Admin Center overview | Microsoft Learn

Windows Admin Center is a remotebrowser-based management toolproduct for Windows Server infrastructure running anywhere—in physical, virtual, on-premises, in Azure, or in a hosted environment—environments at no extra cost. It provides two management experiences: Administration Mode and Virtualization Mode.

To find out what's new, see Release history.

Choose a Windows Admin Center experience

Administration Mode and Virtualization Mode are part of the same Windows Admin Center product, but they serve different management scenarios. They're independent experiences that you install on separate systems, not modes that you switch between in a single deployment.

ExperienceChoose this experience when you need to
Administration ModePerform general administration and troubleshooting for individual servers and clusters. This experience provides tools for areas such as events, certificates, devices, networking, registry, roles and features, storage, and updates.
Virtualization ModeCentrally manage virtualization infrastructure across large-scale, distributed Hyper-V environments. This experience provides resource-focused views and parallel operations for hosts, clusters, virtual machines, storage, and networking.

You can use both experiences in the same environment. To compare their architecture, scale, and capabilities, see What is Windows Admin Center Virtualization Mode?

Windows Admin Center scenarios

  • Simplify server management: Manage your servers and clusters with modernized versions of familiar tools such as Server Manager. Install in under five minutes and manage servers in your environment immediately, no extra configuration required. For details, see What is Windows Admin Center?
  • Work with hybrid solutions: Integration with Azure helps you optionally connect your on-premises servers with relevant cloud services. For details, see Azure hybrid services.
  • Streamline hyperconverged managementManage virtualization infrastructure: Streamline management ofUse Administration Mode to deploy and manage Windows Server hyperconverged clusters. Use simplified workloads to create and manage VMs, Storage Spaces Direct volumes, Software-Defined Networking, and more. For more information, see Manage HCI. Use Virtualization Mode to centrally manage large-scale, distributed Hyper-V resources. For Azure Local management, see the Azure Local documentation.

Related Windows Admin Center management products

Windows Admin Center is designed for managing a single server or cluster. It complements but doesn't replace existing Microsoft monitoring and management solutions, such as Remote Server Administration Tools (RSAT), System Center, Intune, or Azure Stack.

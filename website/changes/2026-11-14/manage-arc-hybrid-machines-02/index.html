Windows Admin Center and Azure Arc
General

Manage Arc Hybrid Machines

14 November 2026Feature update+1 / −1 lines

In brief

The documentation now states that Azure Connected Machine Agent versions 1.65 or earlier cannot upgrade to Windows Admin Center 1.0.0.0 or later. It also retains the guidance that Arc agent versions 1.35 and 1.36 break Windows Admin Center connections, while 1.37 and later fix the issue.

What Windows Server admins need to know

Check Arc agent versions when planning Windows Admin Center upgrades; versions 1.65 or earlier cannot upgrade to Windows Admin Center 1.0.0.0 or later.

Important

Versions 1.35 and 1.36 of the Azure Connected Machine Agent (Arc agent) break connection to Windows Admin Center. Later versions of the Arc agent (1.37+) fix this problem. Additionally, versions 1.65 or lower can't upgrade to version 1.0.0.0 (or later) of Windows Admin Center. You can download the current Azure Connected Machine Agent version here.

By using Windows Admin Center in the Azure portal, you can manage the Windows Server operating system of your Arc-enabled servers, known as hybrid machines. You can securely manage hybrid machines from anywhere without needing a VPN, public IP address, or other inbound connectivity to your machine. To learn more about Arc-enabled servers, see What is Azure Arc-enabled servers?.

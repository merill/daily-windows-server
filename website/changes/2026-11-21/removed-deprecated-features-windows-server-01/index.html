Removed Deprecated Features Windows Server

21 November 2026Retirement+1 / −1 lines

In brief

The documentation states that Windows Server 2028 removes the Windows Server Update Services (WSUS) server role. WSUS remains available and supported in earlier Windows Server releases.

What Windows Server admins need to know

Administrators planning Windows Server 2028 deployments should account for the WSUS role’s removal.

Windows Server 2028 (Preview)

18 November 2026RetirementAction required+37 / −4 lines

In brief

The documentation now lists features deprecated or removed in Windows Server 2028 Preview, including WINS, DirectAccess, SMBv1, VBScript, WMIC, WSUS, legacy BIOS, BranchCache, WDS, and PowerShell 5.1. Plans may change before release.

What Windows Server admins need to know

Inventory dependencies on affected features and plan required migrations, such as moving to DNS, Always On VPN, SMBv2/v3, PowerShell, or UEFI.

We're no longer actively developing these features and might remove them from a future update. Some features were replaced with other features or functionality. Others are now available from different sources. Deprecation means that a feature, functionality, or service is no longer in active development. A deprecated feature might be removed in future releases. A deprecated component still ships in Windows Server, is supported for production deployments, and continues to receive security and quality updates per the product lifecycle.

Windows Server 2028 (Preview)

Important

Windows Server 2028 is in preview. The feature deprecations in this tab don't mean that the features are absent from current preview builds. The features might still be available in current preview builds, and the deprecation plans can change before release.

FeatureExplanation
BranchCacheBranchCache is deprecated beginning with Windows Server 2028. Identify deployments that use BranchCache to cache content from file servers, web servers, or Background Intelligent Transfer Service (BITS), and plan a transition. For more information, see BranchCache.
Windows Deployment Services (WDS) server roleThe WDS server role is deprecated beginning with Windows Server 2028, including its role services, management tools, interfaces, and WDS-provided Preboot Execution Environment (PXE) functionality. You should inventory your WDS dependencies and plan a migration. If you use WDS-backed PXE with Microsoft Configuration Manager, migrate to the Configuration Manager PXE responder without WDS. For more information, see Windows Deployment Services deprecation in the next Windows Server release.
Windows PowerShell 5.1Windows Server 2028 deprecates Windows PowerShell 5.1. Test existing scripts, modules, and management workflows with PowerShell 7, and use the results to plan your migration. Because PowerShell 7 and Windows PowerShell 5.1 have compatibility differences, assess dependencies before migrating. For guidance, see Migrating from Windows PowerShell 5.1 to PowerShell 7.
Windows Sockets DirectWindows Sockets Direct is deprecated. Beginning with Windows Server 2028, system area network (SAN) endpoint creation is disabled by default, and the feature will be removed in a later release. This change doesn't affect NetworkDirect, SMB Direct, or other Remote Direct Memory Access (RDMA) functionality. For more information, see Windows Sockets Direct Architecture.

Windows Server 2025

Feature Explanation

We're removing the following features and functionalities from the installed product image in Windows Server. Applications or code that depend on these features won't function in future releases unless you use an alternative method. Removal occurs when a feature or functionality is no longer available for use and is eliminated from a product or service. The removal of features and functionalities can take place in any release of Windows Server. Some features are deprecated but still ship in current versions of Windows Server. Components aren't removed from generally available supported versions that are within their product lifecycle.

Important

Windows Server 2028 is in preview. The feature removals in this tab aren't confirmation that the features are absent from current preview builds. The features might still be available in current preview builds, and the removal plans can change before release.

FeatureExplanation
Windows Internet Name Service (WINS) server roleWINS is removed in Windows Server 2028 after being no longer developed since Windows Server 2022. Migrate WINS-dependent clients and services to DNS-based name resolution. For more information, see WINS removal: Moving forward with modern name resolution.
DirectAccessDirectAccess is removed from Windows Server 2028. Migrate existing DirectAccess deployments to Always On VPN by using a side-by-side migration. For more information, see Overview of the DirectAccess to Always On VPN migration and DirectAccess deprecation on future Windows Server releases.
Point-to-Point Tunneling Protocol (PPTP) and Layer 2 Tunneling Protocol (L2TP) remote accessRemote access through PPTP and L2TP is removed from Windows Server 2028. Migrate remote access connections to Internet Key Exchange version 2 (IKEv2) or Secure Socket Tunneling Protocol (SSTP). For more information, see Configure VPN protocols and L2TP and PPTP removal.
Server Message Block version 1 (SMBv1)Windows Server 2028 no longer includes SMBv1. Update dependent clients, servers, and devices to use SMBv2 or SMBv3. For more information, see Stop using SMB1.
VBScriptWindows Server 2028 removes VBScript, so scripts and apps that depend on it stop working. Migrate administrative scripts to PowerShell and web scripts to JavaScript. For more information, see VBScript deprecation: Timelines and next steps.
Windows Management Instrumentation command-line utility (WMIC)Windows Server 2028 removes the Windows Management Instrumentation Command-line (WMIC) utility, not Windows Management Instrumentation (WMI). Replace WMIC commands with PowerShell or programmatic WMI queries. For more information, see WMI command line (WMIC) utility deprecation: Next steps.
Windows Server Update Services (WSUS)Windows Server 2028 removes the WSUS server role. This change applies only to Windows Server 2028 and doesn't change WSUS availability or support in earlier Windows Server releases.WSUS remains available and supported in earlier Windows Server releases, including Windows Server 2025, for the duration of each release's support lifecycle. You can continue to use WSUS on those releases to manage updates for supported Windows client and Windows Server releases.Microsoft recognizes the need to manage updates in disconnected and highly controlled environments. We're invested in supporting for these scenarios and we'll share more as the work progresses. For more information about previews of disconnected server patching technologies, contact the Windows Server TAP team.
Legacy basic input/output system (BIOS) supportPC/AT (PCAT) and legacy BIOS boot are removed from Windows Server 2028. Unified Extensible Firmware Interface (UEFI) is required. Windows Server 2028 guest VMs require generation 2 Hyper-V VMs. This requirement doesn't change support for generation 1 VMs that run earlier guest operating systems. For planning guidance, see Should I create a generation 1 or 2 virtual machine in Hyper-V?.
MultiPoint ServicesMultiPoint Services is removed from Windows Server 2028 after being no longer developed since Windows Server 2019. The MultiPoint Connector is available as a Feature on Demand in Windows 11, version 26H2, but won't be included in later Windows releases. Use Remote Desktop Services, in particular Remote Desktop Session Host, for shared desktop and application sessions. For more information, see Remote Desktop Services overview.
Shielded VMsShielded VMs are removed from Windows Server 2028. Use Trusted VMs as an alternative where their capabilities meet your requirements. The preview doesn't support failover clusters or Hyper-V Replica, and VM key portability is limited. For more information, see Trusted Launch for generation 2 virtual machines.
AT Time Service (ATSVC) and AT command (at.exe)The legacy AT Time Service (ATSVC) and its at.exe command-line client are removed from Windows Server 2028. ATSVC was already disabled by default and was superseded by Task Scheduler. Use schtasks instead to schedule commands and programs.
.NET Framework 3.5 optional Windows componentWindows Server 2028 no longer includes .NET Framework 3.5 as an inbox optional component or Feature on Demand. The framework remains available through a standalone installer. For installation guidance, see Install .NET Framework 3.5 on Windows 11. For more information about the deployment change, see .NET Framework 3.5 moves to standalone deployment in new versions of Windows.

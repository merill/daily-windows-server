Smb Feature Descriptions

18 November 2026New feature+15 / −2 lines

In brief

The page now documents SMB Policy Controller (preview), available server-side in Windows Server Insider Preview build 29707 or later. It uses intent-based configuration and reconciliation to maintain server-wide and share-specific SMB settings through PowerShell.

What Windows Server admins need to know

Administrators using the specified Insider Preview build can evaluate PowerShell-based security or performance configuration; no required action is stated.

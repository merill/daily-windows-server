SMBv1 Availability: Windows Server and Windows

19 November 2026Feature updateAction required+19 / −11 lines

In brief

The documentation now states that Windows Server 2028 Preview no longer includes SMBv1 and cannot install or enable it. Windows Server 2019–2025 still omit SMBv1 by default.

What Windows Server admins need to know

Audit SMBv1 usage and update or replace dependent systems before upgrading to Windows Server 2028 Preview.

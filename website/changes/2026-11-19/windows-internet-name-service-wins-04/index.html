Windows Internet Name Service (WINS)

19 November 2026RetirementAction required+17 / −6 lines

In brief

The documentation states that WINS remains supported throughout the Windows Server 2025 lifecycle but has been removed from Windows Server 2028 Preview. It adds guidance for replacing WINS with DNS.

What Windows Server admins need to know

Organizations using WINS should plan a transition to DNS and decommission WINS.

Windows Internet Name Service (WINS) | Microsoft Learn

Windows Internet Name Service (WINS) is a legacy computer name registration and resolution service that maps Network Basic Input/Output System (NetBIOS) computer NetBIOS names to IPInternet Protocol (IP) addresses. Microsoft plans to remove WINS. If your organization still uses it, plan a transition.

This article explains WINS availability and removal plans and provides guidance for migrating name resolution to Domain Name System (DNS).

WINS availability in Windows Server 2025 and planned removal in Windows Server 2028

WINS is available in Windows Server 2025, the final Long-Term Servicing Channel (LTSC) release to include and support it. Microsoft continues to support WINS as part of Windows Server 2025 throughout the Windows Server 2025 lifecycle.

WINS has been removed in Windows Server 2028 Preview. To learn more, see the Windows Server 2028 Preview removal notice. For removal details, see WINS removal: Moving forward with modern name resolution.

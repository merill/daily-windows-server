Should I Create A Generation 1 Or 2 Virtual Machine In Hyper V

19 November 2026Feature updateAction required+5 / −1 lines

In brief

The guidance now says to use Generation 2 VMs for Windows Server 2028 Preview and plan for UEFI firmware on physical Hyper-V hosts running that version. Earlier guest operating system support is unchanged.

What Windows Server admins need to know

For Windows Server 2028 Preview deployments, use Generation 2 VMs and plan for UEFI-equipped physical Hyper-V hosts.

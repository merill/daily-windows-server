General

A cross-product view of Windows Server changes related to General.

Latest General changes

18 November 2026

Configure Github Copilot Cli Local Inference

General

The page now refers to the Windows Server Token factory endpoint instead of the Windows Server inference endpoint in the DNS prerequisite, model ID instructions, and troubleshooting section.

18 November 2026

Configure SMB Policy Controller (preview)

General

The new article describes SMB Policy Controller, which manages and corrects server-wide and share-level SMB intents, including configuration, verification, troubleshooting, and removal. It requires Windows Server Insider Preview build 29707 or later and installation of the PolicyController Feature on Demand.

18 November 2026

Connect Visual Studio Code to a Windows Server Token factory endpoint

General

The article now covers connecting a Windows client to an existing Windows Server Token factory endpoint. It removes same-device scenarios and adds requirements for network reachability, DNS, trusted TLS, and HTTPS.

18 November 2026

Hybrid Intelligence on Windows Server

General

The page now covers distributed, embedded, and on-device inference on Windows Server. It also reframes the integration links around connecting GitHub Copilot CLI and Visual Studio Code to a Windows Server Token factory endpoint.

18 November 2026

Hybrid Intelligence on Windows Server documentation

General

The documentation title, heading, and planning section now use “Hybrid Intelligence.” Integration links now refer to Windows Server Token factory endpoints instead of local or remote model endpoints.

18 November 2026

Smb Feature Descriptions

General

The page now documents SMB Policy Controller (preview), available server-side in Windows Server Insider Preview build 29707 or later. It uses intent-based configuration and reconciliation to maintain server-wide and share-specific SMB settings through PowerShell.

18 November 2026

Windows Server 2028 (Preview)

General

The documentation now lists features deprecated or removed in Windows Server 2028 Preview, including WINS, DirectAccess, SMBv1, VBScript, WMIC, WSUS, legacy BIOS, BranchCache, WDS, and PowerShell 5.1. Plans may change before release.

18 November 2026

Windows Server 2028 Preview: New features

General

A new article describes preview capabilities across identity, management, automation, security, recovery, storage, and virtualization, including PowerShell 7, SMB Policy Controller, and Microsoft Entra ID and Intune management. It identifies the first Insider Preview build for each capability.

17 November 2026

Add Hyper-V Resources in Windows Admin Center

General

The article now covers creating resource groups and onboarding standalone Hyper-V hosts or clusters, with prerequisites for roles, host capacity, supported Windows Server versions, domain and DNS configuration, connectivity, firewall rules, and exclusive management.

17 November 2026

Administration Mode

General

Version 2611 supports registering a Windows Admin Center gateway with Azure RBAC without creating a custom Microsoft Entra application. The article also documents custom-app registration, access models, prerequisites, and supported gateway modes.

17 November 2026

Configure shared connections for all users of the Windows Admin Center gateway

General

The documentation now states that shared connections apply to Windows Admin Center in Administration Mode and not Virtualization Mode. Screenshot descriptions were also improved.

17 November 2026

Configuring user access control and permissions

General

The article now states that its procedures apply only to Administration Mode. It adds Virtualization Mode access requirements, including the Gateway Administrator role and local Administrator rights for VM workflows on managed Hyper-V hosts.

17 November 2026

Index

General

The AI landing page now emphasizes planning and deploying AI inference, adds links for deploying a token factory and using the Foundry Local CLI, and updates the Foundry Local SDK link.

17 November 2026

Manage Failover Clusters

General

The article now states that failover cluster connections apply only to Windows Admin Center Administration Mode. Virtualization Mode uses a different approach for managing virtualization clusters, and the Tools heading was clarified.

17 November 2026

Manage Servers

General

The article now explains that individual servers are added in Administration Mode and directs Virtualization Mode users to add servers as compute resources instead.

17 November 2026

Manage Virtualization Mode Virtual Machines

General

The prerequisite now links to “Add compute resources in Windows Admin Center Virtualization Mode” instead of the more general “Add resources” title.

17 November 2026

Manage VMs in Windows Admin Center Administration Mode

General

The article now covers Windows Admin Center Administration Mode and directs Virtualization Mode users to a separate management article.

17 November 2026

Update the Administration Mode Certificate

General

The article now describes the single gateway HTTPS certificate used in Windows Admin Center Administration Mode, excludes Virtualization Mode, and links to separate Virtualization Mode guidance. It also updates wording and instructions.

17 November 2026

Use Virtualization Mode Vm Templates

General

The VM templates documentation now links to the revised Windows Admin Center Virtualization Mode installation instructions and uses a more specific link title for adding compute resources.

17 November 2026

User access options with Windows Admin Center

General

The documentation now distinguishes Administration and Virtualization Mode access. Virtualization Mode requires the Gateway Administrator role or equivalent permissions, plus local Administrator rights on each managed Hyper-V host for virtual machine workflows.

17 November 2026

Windows Admin Center - Virtualization mode

General

The Hyper-V Replica failover-cluster page no longer includes the notice that configuring replication through Windows Admin Center’s Virtualization mode is in preview and subject to change.

17 November 2026

Windows Admin Center - Virtualization mode

General

The page added two ontology links and removed the note describing Hyper-V Replica configuration through Windows Admin Center’s Virtualization mode as preview software.

17 November 2026

Windows Admin Center - Virtualization mode

General

The page no longer includes the warning that configuring Hyper-V Replica through Windows Admin Center’s Virtualization mode is in preview and may change substantially.

17 November 2026

Windows Admin Center - Virtualization mode

General

The page no longer includes the Important note stating that configuring Hyper-V Replica through Windows Admin Center’s Virtualization mode is in preview and covered by a prerelease disclaimer.

14 November 2026

Failover Cluster Manager

General

The procedure now scopes KB5072033 to every server joining the cluster and replaces checks of FaultDomainAwareness with FaultDomainAwarenessDefault. It also clarifies the storage pool version 29 or later requirement.

14 November 2026

Manage Arc Hybrid Machines

General

The documentation now states that Azure Connected Machine Agent versions 1.65 or earlier cannot upgrade to Windows Admin Center 1.0.0.0 or later. It also retains the guidance that Arc agent versions 1.35 and 1.36 break Windows Admin Center connections, while 1.37 and later fix the issue.

13 November 2026

60-Day Reminder: Windows Server 2016 reaches the end of extended support on January 13, 2027

Message CenterMC1551896 on mc.merill.net ↗Stay informed
General

On January 13, 2027, all editions of Windows Server 2016 will reach the end of extended support. The January 2027 Windows security update will be the last update provided during extended support.

11 November 2026

The Active Directory security best-practices documentation now links to OWASP’s 2025 Top 10 page instead of its former index page.

11 November 2026

Configure AD FS Extranet Smart Lockout Protection

General

The article received updated DevRel metadata links and a minor revision to its description of ESL requests through Web Application Proxy or an MS-ADFSPIP-compatible third-party proxy.

11 November 2026

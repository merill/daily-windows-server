Latest Storage and file services changes

19 November 2026

Detect, enable, and disable SMBv1, SMBv2, and SMBv3 in Windows

General

The documentation now states that Windows Server 2028 Preview does not include SMBv1, so the documented enablement procedures do not apply. It also clarifies that SMBv1 is not installed by default on Windows Server 2019 through 2025.

19 November 2026

SMBv1 Availability: Windows Server and Windows

General

The documentation now states that Windows Server 2028 Preview no longer includes SMBv1 and cannot install or enable it. Windows Server 2019–2025 still omit SMBv1 by default.

18 November 2026

Configure SMB Policy Controller (preview)

General

The new article describes SMB Policy Controller, which manages and corrects server-wide and share-level SMB intents, including configuration, verification, troubleshooting, and removal. It requires Windows Server Insider Preview build 29707 or later and installation of the PolicyController Feature on Demand.

18 November 2026

Smb Feature Descriptions

General

The page now documents SMB Policy Controller (preview), available server-side in Windows Server Insider Preview build 29707 or later. It uses intent-based configuration and reconciliation to maintain server-wide and share-specific SMB settings through PowerShell.

18 November 2026

SMB Policy Controller (preview) overview in Windows Server

Fundamentals

New documentation describes SMB Policy Controller, which stores administrator-defined SMB configurations and keeps managed server and share settings aligned. It covers intent scopes, profiles, workload selectors, reconciliation, and restoring captured settings.

18 November 2026

What is SMB File Sharing for Windows and Windows Server

Fundamentals

The overview now notes that SMB Policy Controller (preview) is available in Windows Server Insider Preview build 29707 or later and Windows 11.

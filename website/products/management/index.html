General

The article now describes Administration Mode as a browser-based Server Manager experience for connecting to individual Windows Server servers and performing common administration tasks. It clarifies the article’s monitoring, configuration, and maintenance coverage, and updates supporting references.

The article explains how gateway administrators can use Windows Admin Center PowerShell modules to manage connection lists and extensions across multiple servers in Administration Mode. It also documents importing and exporting connections and tags, and managing extension feeds and packages.

20 November 2026

User access options with Windows Admin Center

General

The article now explains how gateway access, identity providers, and role-based access control apply in Administration Mode, and how access requirements differ in Virtualization Mode.

20 November 2026

What is Windows Admin Center

Fundamentals

The article now describes Windows Admin Center across on-premises, disconnected, and hybrid environments, clarifies the separate Administration and Virtualization modes, and updates the Administration Mode architecture diagram description.

20 November 2026

Fundamentals

The overview was rewritten to help administrators choose Administration Mode or Virtualization Mode. It also removes the release-history link and updates the Virtualization Mode installation link.

The article now compares Administration Mode and Virtualization Mode, clarifies that installation topologies and operating system requirements apply only to Administration Mode, and adds descriptions of the four Administration Mode topologies.

17 November 2026

General

The article now covers creating resource groups and onboarding standalone Hyper-V hosts or clusters, with prerequisites for roles, host capacity, supported Windows Server versions, domain and DNS configuration, connectivity, firewall rules, and exclusive management.

Administration Mode

General

Version 2611 supports registering a Windows Admin Center gateway with Azure RBAC without creating a custom Microsoft Entra application. The article also documents custom-app registration, access models, prerequisites, and supported gateway modes.

Configure shared connections for all users of the Windows Admin Center gateway

General

The documentation now states that shared connections apply to Windows Admin Center in Administration Mode and not Virtualization Mode. Screenshot descriptions were also improved.

Configuring user access control and permissions

General

The article now states that its procedures apply only to Administration Mode. It adds Virtualization Mode access requirements, including the Gateway Administrator role and local Administrator rights for VM workflows on managed Hyper-V hosts.

17 November 2026

Deploy Windows Admin Center High Availability

Planning and deployment

The article now focuses on deploying an Administration Mode gateway on a failover cluster and states that it does not cover Virtualization Mode. Titles, descriptions, and section headings were also updated.

Planning and deployment

The documentation article for installing Windows Admin Center Virtualization Mode (preview) was deleted, including its prerequisites and setup instructions.

17 November 2026

Install Windows Admin Center

Planning and deployment

The article now explains Administration Mode and Virtualization Mode, interactive and command-line installation, configuration files, TLS, updates, sign-in, and mode-specific prerequisites.

17 November 2026

Manage Failover Clusters

General

The article now states that failover cluster connections apply only to Windows Admin Center Administration Mode. Virtualization Mode uses a different approach for managing virtualization clusters, and the Tools heading was clarified.

17 November 2026

Manage Servers

General

The article now explains that individual servers are added in Administration Mode and directs Virtualization Mode users to add servers as compute resources instead.

17 November 2026

General

The prerequisite now links to “Add compute resources in Windows Admin Center Virtualization Mode” instead of the more general “Add resources” title.

17 November 2026

Manage VMs in Windows Admin Center Administration Mode

General

The article now covers Windows Admin Center Administration Mode and directs Virtualization Mode users to a separate management article.

17 November 2026

Update the Administration Mode Certificate

General

The article now describes the single gateway HTTPS certificate used in Windows Admin Center Administration Mode, excludes Virtualization Mode, and links to separate Virtualization Mode guidance. It also updates wording and instructions.

17 November 2026

Use PowerShell to manage Windows Admin Center settings

PowerShell and automation

The article now describes managing connection lists and extensions across multiple Windows Admin Center servers and states that the commands configure Windows Admin Center in Administration Mode. Its connection import/export heading was also revised.

17 November 2026

Use Virtualization Mode Vm Templates

General

The VM templates documentation now links to the revised Windows Admin Center Virtualization Mode installation instructions and uses a more specific link title for adding compute resources.

17 November 2026

User access options with Windows Admin Center

General

The documentation now distinguishes Administration and Virtualization Mode access. Virtualization Mode requires the Gateway Administrator role or equivalent permissions, plus local Administrator rights on each managed Hyper-V host for virtual machine workflows.

17 November 2026

Virtualization Mode Known Issues

Troubleshooting

The known-issues documentation now identifies the Networking tab in the Add resources workflow, updates the compute-resources link title, and adds a storage-resources link.

17 November 2026

Virtualization Mode Overview

Fundamentals

The documentation now states that hyperconverged storage configuration is unavailable, and that editing a network intent template affects only future deployments. Existing Network ATC intents must be managed with PowerShell cmdlets. The installation link and Networking view terminology were also updated.

17 November 2026

What is Windows Admin Center

Fundamentals

The article now explains the two modes, describes Administration Mode’s direct connections to managed systems, and updates gateway architecture details, including the .NET 10 backend and microservice model.

17 November 2026

Windows Admin Center overview

Fundamentals

The overview now explains Administration Mode for general server and cluster administration and Virtualization Mode for large-scale, distributed Hyper-V infrastructure. It states that they are separate installations on separate systems and can be used together.

17 November 2026

Windows Admin Center: Choose an Installation

Planning and deployment

The article now distinguishes Administration Mode from Virtualization Mode, documents their installation models, and lists Administration Mode topologies. It also states that the two modes cannot be installed on the same system.

14 November 2026

Extension Release Notes

Releases, upgrades and migration

Windows Admin Center version 1.3.0.0 upgrades to .NET 10. Azure Connected Machine Agent version 1.65 or earlier cannot upgrade to this or later Windows Admin Center versions.

14 November 2026

Manage Arc Hybrid Machines

General

The documentation now states that Azure Connected Machine Agent versions 1.65 or earlier cannot upgrade to Windows Admin Center 1.0.0.0 or later. It also retains the guidance that Arc agent versions 1.35 and 1.36 break Windows Admin Center connections, while 1.37 and later fix the issue.

11 November 2026

Migrate Virtual Machines Vm Conversion Extension

Releases, upgrades and migration

The VM conversion guidance now links to Broadcom Support for VMware VDDK 8.0.3 downloads. The required version and extraction path are unchanged.

11 November 2026

Troubleshoot Vm Conversion Extension

Troubleshooting

The VM conversion troubleshooting article now links to a new Broadcom VDDK Programming Guide URL for troubleshooting Changed Block Tracking (CBT).

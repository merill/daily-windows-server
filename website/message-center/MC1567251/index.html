Windows Server 2028 is now available in public preview

24 November 2026MC1567251 on mc.merill.net ↗Message

In brief

What and whyWindows Server 2028 is now available in public preview. This release introduces security, storage, and management improvements and begins investments in hybrid intelligence to support AI inference on local infrastructure.

Message Center announcement

What and why
Windows Server 2028 is now available in public preview. This release introduces security, storage, and management improvements and begins investments in hybrid intelligence to support AI inference on local infrastructure.

The release includes a hardened Server Core configuration by default, a new security baseline, and Trusted Launch for virtual machines. Storage improvements include native NVMe storage enabled by default, NVMe over TCP and RDMA, and the ability to boot from ReFS.

Rollout schedule
  • November 17, 2026: Windows Server 2028 became available in public preview through the Windows Server Insider Program, including security, performance, and management features.
  • Available now: Microsoft Intune management for eligible, persistent Windows Servers is in preview; Windows Admin Center Virtualization Mode is generally available.
  • Limited early access: Hybrid intelligence capabilities are available to a limited number of customers through an early access program, and hardware requirements apply.
  • First half of 2027: AMD's Instinct MI350P accelerator support is expected to enter preview for supported Windows Servers and Windows Server 2028.

Impact on your organization
Administrators can evaluate Windows Server 2028 preview features. Separately, Microsoft Intune management for eligible, persistent Windows Servers is in preview, with workflows for configuration, compliance, applications, and updates. Windows Admin Center Virtualization Mode is generally available for managing individual servers and virtualized infrastructure.

Action required/recommendations
To evaluate the preview, join the Windows Server Insider Program. Organizations interested in hybrid intelligence can apply to the early access program.

For more information, see Windows Server 2028: A trusted foundation for an evolving enterprise.

Compliance considerations
No compliance considerations are identified. Review as appropriate for your organization.

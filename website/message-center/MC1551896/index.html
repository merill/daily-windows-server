60-Day Reminder: Windows Server 2016 reaches the end of extended support on January 13, 2027

13 November 2026MC1551896 on mc.merill.net ↗Message

In brief

On January 13, 2027, all editions of Windows Server 2016 will reach the end of extended support. The January 2027 Windows security update will be the last update provided during extended support.

Message Center announcement

On January 13, 2027, all editions of Windows Server 2016 will reach the end of extended support. The January 2027 Windows security update will be the last update provided during extended support. After that date, monthly security updates will continue only for Windows Server 2016 devices enrolled in Extended Security Updates (ESU).

Support for Windows Server 2016 Essentials features, including Remote Web Access and related Essentials-specific functionality, also ends on January 13, 2027. Any Windows Server 2016 Essentials capability that continues to function after support ends should be treated as unsupported.

To help keep your environment protected and supported, plan to upgrade to Windows Server 2025. To download a free 180-day evaluation, visit the Microsoft Evaluation Center.
 
For detailed lifecycle dates, see the Windows Server 2016 lifecycle page. For servicing timelines and related resources, see Windows Server release information, Lifecycle FAQ - Windows Server, and the Microsoft Lifecycle Policy search tool.

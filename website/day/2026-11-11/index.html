Day in brief

SID-bearing certificate requests: NDES guidance explains SAN, extension, and custom policy-module exception

The 11 November batch was largely documentation maintenance, with the most substantive update in AD CS. NDES guidance now covers certificate requests carrying SID information in the SAN or a separate SID extension, including the custom policy module exception. Other meaningful edits refresh VM conversion links for VDDK 8.0.3 and Changed Block Tracking troubleshooting, while Active Directory and AD FS received narrower reference and wording updates.

  • AD CS · General
    NDES guidance details SID data in SANs and separate certificate extensions

    The AD CS article now describes NDES behavior for requests containing SID information in the SAN or in a separate SID extension, including the exception for custom policy modules. Administrators working on affected enrollment scenarios should consult this guidance during design or troubleshooting.

  • Management · Releases, upgrades and migration
    VM conversion guidance links directly to Broadcom for VDDK 8.0.3

    The migration procedure now points to Broadcom Support for downloading VMware VDDK 8.0.3. The required version and extraction path remain unchanged, so the practical action is to use the updated download link.

  • Management · Troubleshooting
    Changed Block Tracking troubleshooting now uses a new Broadcom guide URL

    The VM conversion troubleshooting article now links to a new Broadcom VDDK Programming Guide URL for Changed Block Tracking troubleshooting. Administrators following the article will be directed to that updated resource.

  • Active Directory · General
    Active Directory security guidance now links to OWASP’s 2025 Top 10

    The Avenues To Compromise article replaces its former OWASP index link with the OWASP 2025 Top 10 page, directing readers to current vulnerability and countermeasure information. No configuration change is required.

  • AD FS · General
    AD FS smart-lockout guidance revises proxy request wording and metadata

    The AD FS extranet smart lockout article received updated DevRel metadata links and a minor revision describing ESL requests through Web Application Proxy or an MS-ADFSPIP-compatible third-party proxy. No administrator action is indicated.

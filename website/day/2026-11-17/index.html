Day in brief

Windows Admin Center guidance splits modes and warns pre-2611 upgrades require re-registration

Microsoft Learn’s Windows Admin Center guidance now clearly separates Administration Mode from Virtualization Mode across installation, access, Hyper-V onboarding, clustering, networking, and virtual-machine procedures. The revised material also documents a significant version 2611 registration caveat, while Hyper-V Replica pages remove preview wording and the standalone Virtualization Mode preview installation article is removed.

  • Management · Planning and deployment
    Virtualization Mode installation now has explicit hardware and lifecycle requirements

    The main installation article now documents both Administration Mode and Virtualization Mode, including interactive and command-line setup. Virtualization Mode requires a dedicated server with at least 4 cores, 8 GB of RAM, and 10 GB of disk space; changing modes later requires reinstallation.

  • Management · General
    Hyper-V resource onboarding gains a detailed prerequisites checklist

    The updated article covers creating resource groups and onboarding standalone Hyper-V hosts or clusters. Administrators are directed to check roles, host capacity, supported Windows Server versions, domain and DNS configuration, connectivity, firewall rules, and exclusive management before onboarding resources.

  • Management · General
    Version 2611 guidance adds a gateway re-registration requirement after upgrades

    The Administration Mode article now says version 2611 can register a gateway with Azure RBAC without creating a custom Microsoft Entra application. Upgrades from before version 2611 do not preserve the existing registration: the gateway is unregistered and users are signed out, so administrators must re-register it and select a registration model with its prerequisites.

  • Management · Fundamentals
    Virtualization Mode networking guidance limits template changes to future deployments

    The Virtualization Mode overview now states that hyperconverged storage configuration is unavailable and that editing a network intent template affects only future deployments. Existing Network ATC intents must instead be managed with Network ATC PowerShell cmdlets.

  • Hyper-V · General
    Hyper-V Replica guidance removes its Virtualization Mode preview notice

    The Hyper-V Replica failover-cluster guidance no longer labels configuration through Windows Admin Center’s Virtualization mode as preview software subject to change. The update changes the page’s qualification and wording without stating a new availability milestone.

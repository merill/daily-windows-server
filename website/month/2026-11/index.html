Month in brief

Windows Server 2028 public preview flags legacy removals and SMB policy control

November brought the public preview of Windows Server 2028, alongside planning guidance that identifies significant legacy-component removals and a new SMB Policy Controller preview. Existing environments also received a stricter LDAP authentication requirement and a Windows Server 2025 out-of-band fix for a narrowly scoped IPv6 routing crash.

  • Windows Server · General
    Windows Server 2028 enters public preview

    Microsoft announced that Windows Server 2028 is available in public preview, with security, storage, and management improvements plus investments in hybrid intelligence for AI inference on local infrastructure. Administrators can evaluate these capabilities for testing and deployment planning.

  • Windows Server · General
    Preview guidance identifies broad Windows Server 2028 removals

    The Windows Server 2028 Preview guidance lists WINS, DirectAccess, SMBv1, VBScript, WMIC, WSUS, legacy BIOS, BranchCache, WDS, and PowerShell 5.1 among features deprecated or removed. The plans may change before release, so dependency inventories should distinguish affected workloads from supported migration paths.

  • Storage · General
    SMB Policy Controller preview requires Insider build 29707 or later

    New Storage guidance describes SMB Policy Controller as a server-side preview capability that manages and corrects server-wide and share-level SMB intents. The documented configuration, verification, troubleshooting, and removal workflows require Windows Server Insider Preview build 29707 or later and the PolicyController Feature on Demand.

  • Windows Server · Planning and deployment
    LDAP authentication now requires Kerberos ticket and LDAP SPN match

    Microsoft says additional LDAP authentication requirements began with the October 13, 2026, Windows security updates. Kerberos service tickets used for LDAP authentication must match the LDAP service principal name registered on the target domain controller, a change highlighted for environments such as NetApp SMB shares.

  • Windows Server · Troubleshooting
    OOB hotpatch addresses Server 2025 IPv6 route stop error

    The November 25 out-of-band update addresses a problem affecting a limited number of Windows Server 2025 systems with Router Advertisement enabled that receive time-bound IPv6 routes. When a route timer expires, affected systems can stop unexpectedly with 0x139, KERNEL_SECURITY_CHECK_FAILURE.

For Windows Server administrators

Use the Windows Server 2028 preview for controlled evaluation and dependency planning. Inventory WINS, DirectAccess, SMBv1, VBScript, WMIC, WSUS, legacy BIOS, BranchCache, WDS, and PowerShell 5.1 dependencies; the supplied guidance points to DNS, Always On VPN, SMBv2/v3, PowerShell, and UEFI as migration paths where applicable. For NetApp SMB deployments using LDAP authentication, verify that Kerberos service tickets match the LDAP SPN on the target domain controller. Review the November 25 OOB update for Windows Server 2025 systems with Router Advertisement enabled that receive time-bound IPv6 routes. Evaluate SMB Policy Controller only on Insider Preview build 29707 or later with the PolicyController Feature on Demand.

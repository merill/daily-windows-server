Month in brief

New NDES guidance covers SID certificate requests through two registry formats

The period’s sole change is a new AD CS procedure for configuring Network Device Enrollment Service (NDES) to accept SID information in certificate requests. It documents registry settings for SAN URI and NTDS CA security extension formats.

  • AD CS · General
    Configure NDES to accept SID information in certificate requests

    The new procedure documents registry settings for the SAN URI and NTDS CA security extension formats. Administrators should enable them only when a trusted component validates the SID, then reset IIS or restart NDES to apply the configuration.

For Windows Server administrators

Enable the settings only when a trusted component validates the SID; incorrect validation could enable impersonation or elevation of privilege. Apply the configuration by resetting IIS or restarting NDES.

Month in brief

NDES SID certificate requests add SAN URI and NTDS CA setup guidance

November was dominated by documentation maintenance, with one substantive AD CS addition: a new NDES procedure for accepting SID information in certificate requests through registry settings for SAN URI and NTDS CA security extension formats. A related update clarifies NDES handling of SID data in the SAN or a separate SID extension, including an exception for custom policy modules. Management guidance now points administrators to VMware VDDK 8.0.3 and an updated Changed Block Tracking resource, while Active Directory guidance links to OWASP’s 2025 Top 10.

  • AD CS · General
    New NDES procedure accepts SID information in certificate requests

    The new AD CS guidance explains registry-based configuration for SID data in SAN URI and NTDS CA security extension formats. It warns that the settings should be enabled only when a trusted component validates the SID, and says to apply the change by resetting IIS or restarting NDES.

  • AD CS · General
    NDES guidance clarifies SAN, SID-extension, and policy-module handling

    The updated article now describes NDES behavior for requests carrying SID information in the SAN or a separate SID extension, including the custom policy module exception. This is relevant when designing or troubleshooting SID-bearing certificate enrollment.

  • Management · Releases, upgrades and migration
    VM conversion guidance links directly to Broadcom’s VDDK 8.0.3 download

    The migration procedure now directs administrators to Broadcom Support for VMware VDDK 8.0.3. The required version and extraction path remain unchanged.

  • Management · Troubleshooting
    VM conversion troubleshooting adopts a new CBT programming-guide link

    The troubleshooting article now links to Broadcom’s updated VDDK Programming Guide for Changed Block Tracking issues, giving administrators a current external reference for CBT troubleshooting.

  • Active Directory · General
    Active Directory security guidance links to OWASP’s 2025 Top 10

    The Avenues To Compromise guidance replaced its former OWASP index link with the 2025 Top 10 page, directing readers to the current vulnerability and countermeasure reference without requiring configuration changes.

For Windows Server administrators

Administrators implementing NDES enrollment for SID-bearing certificates should enable the settings only when a trusted component validates the SID; incorrect validation could enable impersonation or elevation of privilege. Apply the change by resetting IIS or restarting NDES. VM conversion administrators should use the updated Broadcom link for VDDK 8.0.3 and the revised CBT troubleshooting guide. The Active Directory reference update requires no configuration change.

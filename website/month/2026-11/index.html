Month in brief

Chromium XSLT cutoff and Windows Admin Center 2611 drive November actions

November’s clearest operational changes were a hard browser-compatibility deadline and several Windows Server behavior and support changes. Chromium M158 disables browser-native XSLT on November 17, affecting customized RD Web Access pages. Windows Server updates also tighten LDAP authentication requirements and change DNS debug-log handling. Windows Admin Center 2611 adds an Azure RBAC registration path without a custom Microsoft Entra application, but upgrades from earlier versions unregister the gateway and sign users out.

  • Remote Desktop · Releases, upgrades and migration
    RD Web Access customizations face Chromium M158 XSLT cutoff

    Chromium M158 disables browser-native XSLT beginning November 17, 2026. Administrators with affected customizations should leave the updated .aspx pages unchanged, configure a separate stylesheet through RDWebSiteXsltPath, and test sign-in, resource access, and password changes.

  • Windows Server · Planning and deployment
    Windows Server LDAP authentication now requires LDAP SPN alignment

    Starting with the October 13, 2026, Windows security updates, Kerberos service tickets used for LDAP authentication must match the LDAP service principal name registered on the target domain controller. The guidance specifically highlights preventing issues with NetApp SMB shares.

  • Management · General
    Windows Admin Center 2611 changes Azure RBAC registration and upgrades

    Version 2611 supports registering a Windows Admin Center gateway with Azure RBAC without creating a custom Microsoft Entra application. Upgrades from before version 2611 unregister the gateway and sign users out, so administrators must re-register the gateway and select a registration model after upgrading.

  • DNS and DHCP · PowerShell and automation
    DNS Server debug logging adds Event ID 506 and stricter permissions

    With applicable 2026-11 cumulative updates, DNS Server logs Event ID 506 and relocates existing debug logs configured outside C:\Windows\System32\dns\log. Changing LogFilePath requires membership in the local Administrators group; DnsAdmins membership alone is denied.

  • Windows Server · General
    Windows Server 2016 extended support ends January 13, 2027

    All Windows Server 2016 editions reach the end of extended support on January 13, 2027. The January 2027 Windows security update will be the final update provided during extended support.

For Windows Server administrators

Prioritize RD Web Access migration and testing before the November 17 XSLT cutoff where applicable. Verify Kerberos service-ticket and LDAP SPN alignment, review DNS debug-log locations and permissions after applicable 2026-11 cumulative updates, and plan Windows Admin Center 2611 upgrades around gateway re-registration. Include January 13, 2027, in Windows Server 2016 upgrade planning.

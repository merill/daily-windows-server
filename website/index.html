Day in brief

DNS Server adds Event 506 and relocates debug logs outside its default directory

The period’s most consequential guidance concerns DNS logging and Windows Admin Center compatibility. Applicable 2026 cumulative updates are documented as logging DNS Event ID 506 and relocating existing debug logs configured outside `C:\Windows\System32\dns\log`; changing `LogFilePath` now requires local Administrators membership. Windows Admin Center 1.3.0.0 is documented as moving to .NET 10, with Azure Connected Machine Agent 1.65 or earlier unable to upgrade to that version or later. Failover Cluster Manager guidance also tightens the campus-cluster procedure around KB5072033, the fault-domain property, and storage-pool version.

  • DNS and DHCP · PowerShell and automation
    DNS guidance documents new logging and permission behavior

    Starting with applicable 2026 cumulative updates, DNS Server logs Event ID 506 and relocates existing debug logs configured outside `C:\Windows\System32\dns\log`. Changing `LogFilePath` requires membership in local Administrators; DnsAdmins membership alone is denied.

  • Management · Releases, upgrades and migration
    Windows Admin Center 1.3.0.0 moves to .NET 10

    The 1.3.0.0 release upgrades Windows Admin Center to .NET 10. Azure Connected Machine Agent version 1.65 or earlier cannot upgrade to this Windows Admin Center version or later versions.

  • Management · General
    Arc agent guidance preserves connection and upgrade boundaries

    The Arc hybrid-machine guidance states that agent versions 1.65 or earlier cannot upgrade to Windows Admin Center 1.0.0.0 or later. It also records that Arc agent versions 1.35 and 1.36 break Windows Admin Center connections, while version 1.37 and later fix that issue.

  • Failover Clustering · General
    Campus-cluster instructions revise the fault-domain and storage prerequisites

    The Failover Cluster Manager procedure now scopes KB5072033 to every server joining the cluster, replaces `FaultDomainAwareness` checks with `FaultDomainAwarenessDefault`, and clarifies the requirement for storage pool version 29 or later.

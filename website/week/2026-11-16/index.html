Week in brief

Windows Server 2028 Preview flags WINS, SMBv1 and VBScript for removal

Windows Server 2028 Preview is the clear story: the updated overview now places WINS, DirectAccess, SMBv1, VBScript, WMIC, WSUS, legacy BIOS, BranchCache, WDS and PowerShell 5.1 among features deprecated or removed. Focused guidance says WINS and SMBv1 are unavailable, while VBScript-dependent scripts cannot run there. A new SMB Policy Controller preview requires Insider build 29707 or later and the PolicyController Feature on Demand. Windows Admin Center 2611 registration and Generation 2/UEFI guidance add concrete planning steps; much of the remaining activity is mode-specific documentation restructuring.

  • Windows Server · General
    Server 2028 Preview flags a broad set of legacy dependencies

    The updated Windows Server 2028 Preview overview lists WINS, DirectAccess, SMBv1, VBScript, WMIC, WSUS, legacy BIOS, BranchCache, WDS and PowerShell 5.1 among features deprecated or removed. The plans may change before release, but administrators should inventory dependencies and plan migrations to options such as DNS, Always On VPN, SMBv2/v3, PowerShell and UEFI.

  • Administration · Command reference
    VBScript execution is removed from Windows Server 2028 Preview

    The cscript guidance now distinguishes Windows Server 2025, where VBScript is a Feature on Demand, from Windows Server 2028 Preview, which removes VBScript. cscript cannot run scripts requiring the VBScript engine on that release, although Windows Script Host and JScript remain available. VBScript automation should move to PowerShell before testing the preview.

  • Storage · General
    SMB Policy Controller preview adds intent-based configuration and reconciliation

    The new capability manages and corrects server-wide and share-level SMB intents, with guidance for configuration, verification, troubleshooting and removal. Evaluation requires Windows Server Insider Preview build 29707 or later and installation of the PolicyController Feature on Demand.

  • Hyper-V · General
    Hyper-V guidance shifts Windows Server 2028 Preview guests to Generation 2

    The updated Hyper-V guidance recommends Generation 2 VMs for Windows Server 2028 Preview and planning for UEFI firmware on physical Hyper-V hosts running that version. Support for earlier guest operating systems is unchanged.

  • Management · General
    Windows Admin Center 2611 changes gateway registration on upgrade

    Administration Mode guidance says version 2611 supports Azure RBAC gateway registration without creating a custom Microsoft Entra application. Upgrades from versions before 2611 unregister the existing gateway and sign users out, so administrators must re-register the gateway and complete the selected registration model’s prerequisites.

For Windows Server administrators

Inventory dependencies before evaluating or deploying Windows Server 2028 Preview, including WINS, SMBv1, VBScript and the other listed components. Migrate VBScript automation to PowerShell and plan DNS, SMBv2/v3 or UEFI replacements where applicable. If testing SMB Policy Controller, use build 29707 or later with the PolicyController Feature on Demand. For Windows Admin Center upgrades from before version 2611, plan gateway re-registration and account for users being signed out; for Windows Server 2028 Preview guests, use Generation 2 VMs and plan UEFI-capable physical hosts.

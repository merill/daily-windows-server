Week in brief

AD FS guidance details CLDAP discovery and recommends Smart Lockout and egress restrictions

The week's most consequential update is an AD FS FAQ explanation that unrecognized domain identifiers in username and password requests can trigger domain-controller discovery through DNS SRV queries and CLDAP pings. It recommends Extranet Smart Lockout for Windows Server 2019 and later and restricting outbound CLDAP, with authentication—including cross-forest flows—tested after firewall changes. Other useful updates clarify NDES handling of SID-bearing certificate requests and refresh links used by VM migration and Active Directory security guidance.

  • AD FS · Troubleshooting
    AD FS FAQ explains domain discovery caused by unrecognized identifiers

    The FAQ now describes how unknown domain identifiers in username and password requests can initiate domain-controller discovery, including DNS SRV queries and CLDAP pings. It recommends Extranet Smart Lockout on Windows Server 2019 and later and restricting outbound CLDAP; authentication, including cross-forest authentication, should be checked after applying firewall restrictions.

  • AD CS · General
    NDES guidance covers SID data in certificate requests

    The updated guidance explains NDES behavior when certificate requests carry SID information in the subject alternative name or in a separate SID extension, including the exception for custom policy modules. Review it when troubleshooting or designing SID-aware NDES enrollment.

  • Management · Releases, upgrades and migration
    VM conversion guidance points administrators to VDDK 8.0.3 downloads

    The migration procedure now links to Broadcom Support for VMware VDDK 8.0.3. The required version and extraction path remain unchanged, so administrators following the procedure should use the new download destination.

  • Active Directory · General
    Active Directory security guidance now links to OWASP’s 2025 Top 10

    The Avenues To Compromise article replaces its former OWASP index link with the OWASP 2025 Top 10 page, directing readers to the current vulnerability and countermeasure information without requiring configuration changes.

For Windows Server administrators

AD FS administrators should review the Smart Lockout and outbound-CLDAP recommendations against their deployments and validate authentication after any firewall changes. AD CS and migration administrators should use the updated enrollment guidance and VDDK download link; the Active Directory OWASP link update requires no configuration change.

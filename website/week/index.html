Week in brief

Chromium’s XSLT cutoff sets a November 17 RD Web Access migration deadline

The week’s most immediate administrator deadline is Chromium M158 disabling browser-native XSLT on November 17, 2026, affecting customized RD Web Access pages. Windows Server also introduced an LDAP authentication requirement for Kerberos service-ticket and LDAP SPN matching, while applicable 2026-11 cumulative updates alter DNS debug-log handling. Windows Server 2016 extended support ends January 13, 2027, and Windows Admin Center 1.3.0.0 adds an Azure Connected Machine Agent compatibility gate. Additional AD FS guidance covers Extranet Smart Lockout and outbound CLDAP restrictions; most remaining edits were documentation and procedure maintenance.

  • Remote Desktop · Releases, upgrades and migration
    RD Web Access customizations need migration before Chromium M158 disables browser-native XSLT

    New guidance states that Chromium M158 disables browser-native XSLT beginning November 17, 2026. Affected deployments should leave the updated .aspx pages unchanged, configure a separate stylesheet through RDWebSiteXsltPath, and validate sign-in, resource display, and password-change workflows.

  • Windows Server · Planning and deployment
    Windows Server LDAP authentication now requires Kerberos tickets to match the target LDAP SPN

    Microsoft’s security notice says the October 13, 2026, Windows security updates introduced additional LDAP authentication requirements for domain controllers. Kerberos service tickets used for LDAP authentication must match the LDAP service principal name registered on the target domain controller, a requirement called out for preventing NetApp SMB share issues.

  • DNS and DHCP · PowerShell and automation
    DNS Server changes debug-log placement and restricts LogFilePath changes

    With applicable 2026-11 cumulative updates, DNS Server logs Event ID 506 and relocates existing debug logs configured outside C:\Windows\System32\dns\log. Changing LogFilePath requires local Administrators membership; DnsAdmins membership alone is denied.

  • Windows Server · General
    Windows Server 2016 extended support ends January 13, 2027

    All Windows Server 2016 editions reach the end of extended support on January 13, 2027. The January 2027 Windows security update will be the last update provided during extended support.

  • Management · Releases, upgrades and migration
    Windows Admin Center 1.3.0.0 blocks upgrades from older Arc agents

    Windows Admin Center 1.3.0.0 upgrades to .NET 10, and Azure Connected Machine Agent version 1.65 or earlier cannot upgrade to this or later Windows Admin Center versions. The documented upgrade path therefore requires updating the agent first.

For Windows Server administrators

Administrators with affected RD Web Access customizations should migrate before November 17 and test sign-in, resource access, and password changes. For NetApp SMB environments using LDAP authentication, verify that Kerberos service tickets match the LDAP SPN registered on the target domain controller. After applicable 2026-11 updates, review DNS debug-log locations and use a local Administrators account for LogFilePath changes; DnsAdmins membership alone is insufficient. Include the January 13, 2027, Windows Server 2016 support deadline in upgrade planning, and update Azure Connected Machine Agent version 1.65 or earlier before upgrading Windows Admin Center 1.3.0.0 or later.

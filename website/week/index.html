Week in brief

Windows Admin Center 2611 supports Azure RBAC registration without custom app

The period’s main development is a restructuring of Windows Admin Center guidance around separate Administration and Virtualization modes. Version 2611 adds a simpler Azure RBAC registration path, while the updated Hyper-V material defines stricter onboarding prerequisites and important Virtualization Mode limits. The standalone Virtualization Mode preview installation article was also removed.

  • Management · General
    Version 2611 changes Azure RBAC gateway registration on upgrade

    Administration Mode guidance says version 2611 supports registering a Windows Admin Center gateway with Azure RBAC without creating a custom Microsoft Entra application. Upgrading from before version 2611 unregisters the gateway and signs users out; administrators must re-register it, select a registration model, and complete its prerequisites.

  • Management · Planning and deployment
    Mode selection now controls Windows Admin Center installation requirements

    The installation article distinguishes Administration Mode from Virtualization Mode and says the mode must be chosen before installation. Changing modes later requires reinstallation, and Virtualization Mode requires a dedicated server with at least 4 cores, 8 GB of RAM, and 10 GB of disk space.

  • Management · General
    Hyper-V onboarding guidance adds host, network, and exclusivity prerequisites

    Add Hyper-V Resources now covers resource groups and onboarding standalone Hyper-V hosts or clusters. Its prerequisites include the required roles, host capacity, supported Windows Server versions, domain and DNS configuration, connectivity, firewall rules, and exclusive management; verify these conditions before onboarding resources.

  • Management · Fundamentals
    Virtualization Mode documents storage and Network ATC limits

    The overview states that hyperconverged storage configuration is unavailable. Editing a network intent template affects only future deployments, while existing Network ATC intents must be managed with PowerShell cmdlets.

  • Management · Planning and deployment
    Standalone Virtualization Mode preview installation article was removed

    The article for installing Windows Admin Center Virtualization Mode (preview) was deleted, including its prerequisites and setup instructions. Administrators using the former documented URL will no longer find that installation guidance there.

For Windows Server administrators

Plan 2611 upgrades for gateway re-registration and user sign-in disruption. Choose the Windows Admin Center mode before deployment, verify Virtualization Mode host and access requirements, and do not expect network intent template edits to change existing deployments. Administrators relying on the deleted preview installation page should use the current mode-specific installation guidance.
